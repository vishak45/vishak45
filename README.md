# Vishak R Portfolio

This repository now includes a lightweight static portfolio website built with plain HTML, CSS, and vanilla JavaScript.

## Run Locally

You can run it in either of these simple ways:

1. Open `/home/runner/work/vishak45/vishak45/index.html` directly in your browser.
2. Or serve the repository with a basic static server, for example:
   ```bash
   cd /home/runner/work/vishak45/vishak45
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`.
